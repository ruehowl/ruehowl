### Hi, I'm Rahul 👋

SRE turned founder, based in Kerala, India. I spent nine years as an SRE (Kubernetes, observability, multi-tenant SaaS) and now build tools so a small team can start with the platform discipline of a big one.

**Creator of:**

- **[Orun](https://github.com/sourceplane/orun)**: an open-source (MIT), single-binary CLI that writes your platform down as code. Environments, pipelines and policy live in `intent.yaml` next to the code; `orun plan` turns a change into one job per component per environment, and `orun run` executes it.
- **[Orunbase](https://orunbase.com)**: the hosted console on top of Orun. Pick a baseline and a production-grade platform builds itself into your repo, with approvals, an audit log, and an MCP surface so coding agents work inside the same guardrails. Free for two workspaces.

Orunbase runs on itself: its own control plane is built and deployed by Orun on every commit.
